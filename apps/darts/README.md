# Darts

The game owns ballistic flight, impacts, score rules, turns and input semantics.
Hyperfy provides player identity, transports commands/snapshots, schedules the
game and displays its output. Darts do not use Hyperfy/PhysX rigid bodies.

`game.js` and `controller.js` run independently of Hyperfy. `server.js` validates
sender identity and command sequence, supplies the player's authoritative position,
then calls the game. `client.js`
supplies raw keys/pointer deltas and applies the game's display poses. `render.js`
contains only world geometry, score panels and dart transforms.

Play solo or with up to four connected players. Point at the board and press E to join;
the first player hosts. In the lobby M cycles Count Up, 301, 501 and Cricket;
Space starts. Normal camera look aims, arrows fine-tune aim, Q/Z changes launch speed, and Space
throws. The amber sight previews the ballistic impact. After three darts,
Space clears the visit and advances the turn. Countdown games require double-out;
bust restores the score at the beginning of the visit. Count Up lasts eight
rounds. Cricket closes 15–20 and bull, with scoring against open opponents.
R returns the host's match to the lobby; Esc restores normal world controls while
retaining membership; X leaves the match. Disconnect removes the player.
WASD movement, mouse look and wheel zoom retain their normal Hyperfy behavior,
including third person. The game never moves the player or writes the camera.
There is no enforced throwing distance or automatic exit radius.

Space begins a 0.45-second wind-up before launch. The right-arm Mixamo clip
plays through Hyperfy's native emote effect with this fork's `m=rightArm`
overlay, preserving walking and head look. The displayed held dart follows the
right hand, including for spectators during wind-up. The game samples the
authenticated player's actual position at release and launches its own physics;
animation bones never determine authoritative impacts. Reload an already-open
world after installing the updated runtime. The arm mask requires this fork's
updated client, not only importing the `.hyp` into stock Hyperfy.

Flight uses BananaDarts' analytic projectile equations with Earth gravity,
metres and seconds. The board uses Dart Room's pure geometry and scoring helpers
with regulation steel-tip radii. The release follows the player's current feet
position with a 1.55 m hand height and 0.27 m arm reach in the throwing direction.
The server derives that origin from the authenticated player, not a client-supplied
origin. The lane markings are a reference; changing position changes the physical
flight. Floor misses terminate at the thrower's floor height. No random impact is substituted for flight.
This model omits aerodynamic drag, wire bounce-outs and collisions between darts.
Matches are live session state, cleared when the app/server rebuilds.

Build and test:

```sh
npm run build:darts
npm run test:darts
```

To reproduce `throw.glb` from its pinned source, run
`node apps/darts/prepare-throw.mjs`. The source hash and Adobe usage terms
are recorded in `THIRD_PARTY.md`.

The checked-in `board.png` is generated by `board.py` using Pillow. Build produces
`outputs/darts/darts.hyp`, the exact bundled script, an interactive exact-package
preview and a reusable worldsync catalog object. `THIRD_PARTY.md` records pinned
upstream revisions and modifications. `VALIDATION.md` records the package,
runtime and two-browser checks.

To install the machine separately, drag `outputs/darts/darts.hyp` into Hyperfy
with builder permission. The single file embeds the cabinet/game script,
dartboard artwork, throw animation and bootstrap model. Native import creates
a new app blueprint and instance with its own match state. The package contains
no cottage, billiards, cue-rack or scene dependencies. The right-arm animation
overlay still requires the updated Hyperfy fork described above.

For a disposable local playtest, run `node apps/darts/serve-local.mjs`, then open
`http://127.0.0.1:8766`. Ctrl-C removes the temporary world. For a deployment plan,
run `node apps/darts/deploy.mjs`; `--write` registers the source and adds one
station beside the cue rack in the configured 3333 world. That external write
was approved and completed; the source is registered in `hyperfy-world-jerome`
and the live station has been checked in the browser.
