# Larch House

Import `luxury_log_cabin.hyp` into the Hyperfy build that supports native `prim` extrusions. The editable application source is `luxury_log_cabin.js`.

Open `luxury_log_cabin_preview.html` in a browser for a self-contained, interactive preview. It embeds the exact delivered `.hyp` bytes and this checkout's actual primitive constructor and geometry code. The camera buttons include exterior, four elevations, entrance, mezzanine, stairs and a roof-off plan. Studio lighting and the background ground plane belong only to the preview.

## Architecture

- Log-wall footprint: 18 × 15 m; roof overhangs reach approximately 19.9 × 17 m.
- Ground contact: Y=0; finished main floor: Y=0.12 m; mezzanine: Y=3.30 m.
- Wall/eave line: Y=6 m; roof ridge: Y=9.8 m; chimney cap: Y=11.265 m.
- The approved roof compromise preserves the requested ridge height with a 22.9° gable.
- Three rear bedrooms, each approximately 5.6–5.8 × 2.9 m clear, with 2.61 m ceiling clearance, exterior windows and real door openings.
- Approximately 39% of the footprint has a second floor. The central/front great room stays open to the exposed roof.
- A 4.6 m stone fireplace has an actual recessed arch, projecting hearth, timber mantel, tapered extruded chimney and a flashed roof penetration.
- L staircase: 18 risers of 176.7 mm, 320 mm going, nominal 1.35 m tread width and a landing. Stringers, treads and rails share one path.
- Fixed open wooden entrance and bedroom doors; no furniture or fire.

This is the requested **static visual model**. It has no collision, animation, interaction or update callbacks. Walking on the mezzanine in a live world requires a separate structural collision pass.

All 1,584 visible primitives are generated by the JavaScript. There are no external meshes, images or textures. The package includes a tiny, geometry-free GLB solely for compatibility with Hyperfy loaders and the skill's packaging tools; it contains no meshes, materials or textures.

## Verification

`validation_report.json` records actual primitive construction/mounting, finite geometry, ground contact, stair alignment and clearance, log-wall openings, bedroom access, the entrance-to-fireplace sightline, chimney penetration, package hashes, canonical script MIME, and exact source/preview correspondence. The skill self-tests and source/package validators also pass. The running Hyperfy world was not modified or used for an import test.

To regenerate inside this repository:

```sh
node outputs/luxury-log-cabin/build_cabin.mjs
```

The build uses the local Hyperfy skill's packer, extractor, validator and embedded-preview tool. It corrects the packer's script MIME to the target runtime's `text/plain` convention and verifies the extracted bytes.
